Abstract

3. The Aperture and Quantum Tunneling Alliance

When the shielding is near-total, a single, atomically sharp aperture (a nozzle) is introduced into the geometric geometry of the shield.

The material interface undergoes a non-destructive phase change, turning a solid insulator into an open topological channel.
